Tu estudio personal de auto clipping.

Pega una URL de contenido propio o autorizado. CLIPRD envía el trabajo directamente al motor instalado en tu computadora, donde yt-dlp y FFmpeg descargan y generan los MP4. Así no dependes de un servidor remoto para procesar.

Debe ejecutarse en esta misma computadora con npm start dentro de cliprd-agent.

La selección automática actual crea una distribución inteligente de segmentos editables. La detección semántica real de “mejores momentos” requiere analizar audio/transcripción; no se muestra como terminada hasta implementar ese motor.
