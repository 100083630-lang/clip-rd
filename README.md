# CLIPRD 5.0

Aplicación reconstruida desde cero.

## Inicio
```bash
npm install
npm start
```

Abre http://127.0.0.1:3847

El servidor incluye:
- Auto Clip con progreso
- Biblioteca local
- Monitor de trabajos
- Live Monitor
- API health en /health

Requisitos externos: `yt-dlp` y `ffmpeg` disponibles en PATH.
